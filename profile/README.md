# Kinetix

Application web d'analyse vidéo de sport : import d'un match, suivi des joueurs et du ballon, statistiques et exports.

Projet intégrateur réalisé à l'INSA Toulouse.

## Dépôts

| Dépôt | Rôle |
|---|---|
| `kinetix-front` | Application web React |
| `kinetix-backend` | Services `api`, `auth`, `converter` et `export` |
| `kinetix-vision` | Modules d'intelligence artificielle et entraînement |
| `kinetix-infra` | Déploiement et configuration des serveurs |
| `.github` | Modèles et workflows communs |
